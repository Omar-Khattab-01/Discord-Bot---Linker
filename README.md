# Linker Discord Bot

Linker was my first Discord bot. I built it to organize online lecture links and retrieve them quickly without searching through old messages.

## What it does

- Save a lecture link with a keyword and time.
- Retrieve a saved link from Discord.
- List the saved keywords and links.
- Enable or disable scheduled link notifications.
- Keep link records in local files.

The project combines Python, Discord bot interactions, and a small desktop notification interface. It reflects an early project built around a practical problem in my own studies.
